# SIS Astro Website Starter

A responsive agency landing page concept for SIS with:
- Light and dark themes (preference saved in localStorage)
- Six animated sections
- CSS-built robot mascot and service illustrations
- Scroll reveal effects and responsive layouts
- Basic SEO metadata and semantic page structure
- Reduced-motion accessibility support

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Vercel should detect Astro automatically.
4. Use `npm run build` as the build command and `dist` as the output directory.

## Before publishing
- Replace `hello@sis.example` with your real business email.
- Add the final SIS logo and approved robot artwork if available.
- Add real case studies, contact details, social links, and legal pages.
- Add a sitemap integration and verify metadata, domain, and Google Search Console.
